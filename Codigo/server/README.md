This folder contains the server for the clinic management system.

# Node package manager

For this project, we are using pnpm as our package manager. If you don't have it installed, you can install it by running `npm install -g pnpm`.

## Running the server

1. Run `pnpm install`
2. Create a `.env` file and copy paste the content of `.env.example` to it.
3. Run `pnpm dev`
