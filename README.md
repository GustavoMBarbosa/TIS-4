# MedSync

    Durante a jornada de trabalho de uma clínica, diversos pacientes são admitidos. Para o médico, então, pode ser difícil de lembrar as informações relevantes de cada paciente. Assim, a boa organização de informações é importante para que o médico consiga garantir o melhor cuidado possível. Nossa cliente, Danielle Ferraz, vive essa realidade ao administrar uma clínica médica e buscamos, então, auxiliá-la por meio do MedSync.
    Sendo assim, nosso sistema busca organizar os dados da clínica. O sistema engloba dados referentes à consultas, como o agendamento, aos pacientes, como remédios e tratamentos, assim como questões da clínica, como funcionários e documentos financeiros.  Esperamos que o sistema auxilie o bom funcionamento da clínica por meio da facilidade e velocidade do acesso dos dados relevantes.

## Instruções de utilização

O sistema é construido em duas partes principais, o frontend e o backend.

### Pré-requisitos

-   Node.js (versão 16 ou superior)
-   npm ou yarn

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/ICEI-PUC-Minas-PPLES-TI/plf-es-2024-2-ti4-1247100-clinica.git
```

2. Navegue até o diretório do projeto:

```bash
cd plf-es-2024-2-ti4-1247100-clinica
```

### Frontend

Construido em Nuxt.js, o frontend é a interface do usuário do sistema.

1. Navegue até o diretório do projeto:

```bash
cd client
```

2. Instale as dependências:

```bash
npm install
```

3. Execute a aplicação:

```bash
npm run dev
```

### Backend

Construido em Node.js utilizando o framework Express, o backend é a API do sistema.

1. Navegue até o diretório do projeto:

```bash
cd server
```

2. Instale as dependências:

```bash
npm install
```

3. Execute a aplicação:

```bash
npm run dev
```
